# GIS Definition

Geographic Information System - collect, store, analyse, visualise and interpret `spatially referenced data`

Made of `Spatial Localtion Data` and `Attribute Data`: `where something is` and `what something is`

Used in

- Data processing
- Spatial analysis
- `Map making`
- Imagery and remote sensing
- Data collection and management

# GIS data

Stored in either as `vector data` and `raster data`
